# Лабораторные работы по машинному и глубокому обучению

## Общее описание
Данный репозиторий содержит комплекс выполненных заданий, охватывающих ключевые области анализа данных, классического машинного обучения и глубокого обучения. 
Проект демонстрирует применение различных математических методов и архитектур нейронных сетей для решения задач классификации, регрессии, кластеризации и оптимизации на медицинских, текстовых и визуальных данных.

## 🛠 Стек технологий
* **Язык:** Python 3
* **Обработка данных:** `pandas`, `numpy`, `scikit-learn`
* **Глубокое обучение:** `TensorFlow`, `Keras`
* **Компьютерное зрение:** `OpenCV` (HOG, Canny)
* **Нечеткая логика:** `scikit-fuzzy`
* **NLP:** `NLTK`, `SpaCy`
* **Feature Engineering:** `featuretools`, `woodwork`
* **Визуализация:** `matplotlib`, `seaborn`

## Структура и применяемые алгоритмы

### `KNN.ipynb` | Метод K-ближайших соседей и импутация
**Датасет:** Diabetes
**Реализуемые алгоритмы:**
* **KNN-классификатор:** `KNeighborsClassifier` для задач классификации.
* **KNN-импутация:** `KNNImputer` для восстановления пропущенных значений на основе K-ближайших соседей.
* **Метрики расстояний:** Евклидово, Манхэттенское, Минковского.
* **Подготовка данных:** Нормализация признаков (`StandardScaler`), подбор оптимального `k`.

###  `Алгоритмы обработки естественного языка.ipynb` | NLP-пайплайн и векторизация
**Датасет:** Phone Reviews
**Реализуемые алгоритмы:**
* **Векторизация текста:** `CountVectorizer` (Bag of Words) и `TfidfVectorizer` (TF-IDF).
* **NLP-пайплайн:** токенизация, лемматизация, стемминг, POS-тегирование, работа с N-граммами.
* **Регрессия:** `Ridge Regression` (L2-регуляризация) для предсказания рейтинга.
* **Оценка:** RMSE (Root Mean Square Error).

### `Извлечение признаков HOG.ipynb` | Классическое компьютерное зрение
**Датасет:** Fruits Dataset Images
**Реализуемые алгоритмы:**
* **Дескрипторы признаков:** HOG (Histogram of Oriented Gradients).
* **Фильтрация изображений:** детектор границ Canny, CLAHE.
* **Аугментация:** горизонтальное отражение (`cv2.flip`).
* **Классификация:** Метод опорных векторов (`SVM`).

### `Кластеризация.ipynb` | Обучение без учителя и сегментация
**Датасет:** Stroke Prediction / Diabetes
**Реализуемые алгоритмы:**
* **Кластеризация:** `KMeans` (метод Ллойда) и `AgglomerativeClustering` (иерархическая с линковкой Уорда).
* **Понижение размерности:** `PCA` для визуализации многомерных данных в 2D/3D.
* **Метрики качества:** Silhouette Score, Davies-Bouldin Index, Calinski-Harabasz Index.
* **Глубокое обучение (бейзлайн):** Полносвязные сети (`Dense`, `BatchNormalization`, `Dropout`), функции потерь `MSE` и `binary_crossentropy`.

### `Конструирование признаков.ipynb` | Feature Engineering
**Датасет:** Diabetes
**Реализуемые алгоритмы:**
* **Дискретизация (биннинг):** группировка непрерывных признаков (Glucose, Insulin, BMI) по категориям.
* **One-Hot Encoding:** кодирование категориальных признаков.
* **Ручное конструирование:** создание новых признаков (например, HOMA-IR).
* **Автоматическая генерация:** `featuretools` и `woodwork` (EntitySet, Deep Feature Synthesis).

###  `Нечеткая логика.ipynb` | Fuzzy Logic и деревья решений
**Датасет:** Stroke Prediction Dataset
**Реализуемые алгоритмы:**
* **Нечеткая логика (Fuzzy Logic):** система нечеткого вывода (`scikit-fuzzy`), фаззификация и дефаззификация.
* **Правила нечеткого вывода:** оценка риска на основе лингвистических переменных.
* **Классификация:** `DecisionTreeClassifier` как бейзлайн, визуализация дерева, матрица ошибок (Confusion Matrix).
* **Статистика:** Пирсоновский корреляционный анализ.

###  `Продвинутое машинное обучение.ipynb` | Ансамбли и пайплайны
**Датасет:** Diabetes
**Реализуемые алгоритмы:**
* **Импутация пропусков:** `IterativeImputer`, `KNNImputer`.
* **Пайплайны:** `scikit-learn Pipeline` и `ColumnTransformer` для предотвращения утечки данных.
* **Подбор гиперпараметров:** `GridSearchCV`.
* **Классификация:** `LogisticRegression`, `RandomForestClassifier`.
* **Регрессия:** `LinearRegression`, `DecisionTreeRegressor`, `GradientBoostingRegressor`.
* **Метрики:** ROC-AUC, Recall, F1-score, MAE, RMSE, R².

### `Сверточные нейронные сети.ipynb` | Deep Learning для изображений
**Датасет:** Fruits Dataset Images
**Реализуемые алгоритмы:**
* **Собственная CNN:** архитектура на базе слоев `Conv2D`, `MaxPooling2D`, `Flatten`, `Dense`, `Dropout`.
* **Transfer Learning:** использование предобученной `VGG19` (веса ImageNet) в качестве экстрактора признаков.
* **Аугментация данных:** `RandomFlip`, `RandomRotation`, `RandomZoom`, `RandomContrast`.
* **Обучение:** подбор `batch_size`, `epochs`, функций активации (ReLU, Softmax).

###  `Теория и практика кластерного анализа.ipynb` | Метрики расстояний и иерархия
**Датасет:** Diabetes
**Реализуемые алгоритмы:**
* **Теория:** метрики расстояний (Евклидова, Хемминга, Чебышева, Манхэттенское).
* **Кластеризация:** Иерархическая кластеризация с линковкой Уорда (`linkage='ward'`), построение дендрограмм.
* **Понижение размерности:** `PCA` (метод главных компонент) для 2D и 3D визуализации.
* **Анализ:** метод локтя, силуэтный коэффициент, профилирование кластеров.
